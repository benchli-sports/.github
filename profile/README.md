# benchli

**Built for teams. Made for players.**

[benchli.com](https://www.benchli.com/) · [Status](https://status.benchli.com/) · Made in Switzerland 🇨🇭

</div>

---

benchli runs the amateur team you play on, for every team sport, everywhere.

- **For players:** you're in with one tap. Your card, your stats and your history follow you across every team and every sport you play.
- **For whoever runs the team:** we handle the boring bits. RSVPs, a full squad on game day, fill-ins when you're short, and subs collected without the awkward chat.

Most of the time that's the same person, so switching between running it and playing it is seamless.

## Open source

Some of what we build is useful beyond benchli, so we share it.

| Project | What it is |
|---|---|
| [**open-team-sports-data-standard**](https://github.com/benchli-sports/open-team-sports-data-standard) | **OTSD**: an open format for a team's everyday data (players, games, RSVPs, appearances, stats, seasons), so a team can take its history with it from one app to the next. Schemas, a portable package format and an API profile. Apache-2.0. |
| [**codeterrain**](https://github.com/benchli-sports/codeterrain) | **terrain**: fast, local answers about your code for coding agents (definitions, references, test fixtures and their setup order, routes, front-end HTTP calls), with no model calls. Python first, with Terraform and TypeScript packs. `pip install codeterrain`. Apache-2.0. |

Issues and pull requests are welcome on both.
